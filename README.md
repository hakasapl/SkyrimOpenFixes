# Skyrim Open Fixes

An SKSE plugin for Skyrim: Special Edition and Skyrim: VR that aims to compile engine fixes from several other mods into a single mod.

## Pilot Information

This repo is setup as a pilot. Everything is subject to change. Initially, it is set up with just a few ported fixes from `Bottle` (who has approved ports for this pilot): the individual fixes from `Shadow Scene Node Crash Fix` and `LOD Refresh Bug Fix`. It is intended to be a demonstration of the project structure and policies. During the pilot evaluation period we will gauge mod author reception to this project, refine the [Potential Fixes](POTENTIAL_FIXES.md) file to include all mods that would be in-scope of this project (Note that this file is a first pass, there are likely mods in there that should not fix this project, and mods that would but were missed), and also refine the [Contributing](CONTRIBUTING.md) document. If this project launches, this repository will no longer be a pilot.
