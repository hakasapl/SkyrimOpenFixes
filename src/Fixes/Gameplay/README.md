# Gameplay

Fixes for game rules that no other category covers: items and inventory, crafting, lockpicking and pickpocketing, crime and stealth, skills, levelling and perks outside combat and magic, survival mode, races and character creation, quests, and the world's objects.

This is the catch-all: if no other category fits, the fix goes here. Fixes here make the game work as it was designed; changing the design itself is out of scope (CONTRIBUTING.md).
